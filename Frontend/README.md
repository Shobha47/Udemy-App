# smart-skills-india LMS Mobile App

Production-ready Udemy-like LMS mobile application built with:
- React Native
- Expo
- TypeScript
- Zustand
- TanStack Query
- Axios
- React Navigation
- NativeWind

## Setup

```bash
npm install
npx expo start
```

## Environment

Create `.env`:

```env
EXPO_PUBLIC_API_URL=https://your-api.com/api/v1
```
